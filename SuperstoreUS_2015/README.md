📊 Superstore US 2015 | Excel Dashboard & Insights

🌍 Overview

This project provides an in-depth analysis of Superstore US 2015 sales, profits, and returns using Excel dashboards. The dashboard includes interactive visualizations, pivot tables, slicers, and KPIs, offering a comprehensive view of key business metrics such as revenue trends, top-performing products, and customer behavior.

📌 Features

📊 Interactive Dashboard: Dynamic slicers and filters for easy data exploration

📈 Sales & Profit Analysis: Revenue and profit trends by category, region, and customer segment

🛋 Top-Selling Products: Identify best-performing products and customer preferences

🌍 Regional Insights: Performance breakdown by states and cities

🛋 Return Analysis: Examine return rates and their impact on profitability

🔧 How to Use

1️⃣ Download the Excel file from the repository2️⃣ Enable Editing if prompted3️⃣ Use Slicers & Filters to explore different insights dynamically4️⃣ If the file is in Read-Only Mode, enable "Edit" permissions before using slicers
