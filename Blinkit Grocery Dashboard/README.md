🛒 Blinkit Grocery Data Analysis | Excel Dashboard & Insights

📊 Overview
This project provides an in-depth analysis of Blinkit's grocery sales using Excel dashboards. It includes interactive pivot tables, slicers, and charts to visualize key grocery metrics like sales trends, customer preferences, product performance, and regional demand.

Here’s how I approached it:
✅ Data Cleaning & Transformation – Used Power Query to clean and format raw sales data.
📊 KPI-Based Analysis – Defined key metrics like total revenue, item-wise sales, and customer demand.
🎛️ Interactive Slicers & Filters – Enabled dynamic insights with multiple slicers for easy exploration.
🎨 Custom Formatting & Icons – Enhanced visualization for a sleek and intuitive user experience.
⚙️ VBA Automation – Assigned a macro button to clear all filters instantly.

🔧 How to Use
📥 Download the Excel file from the repository.
✅ Enable Editing if prompted.
🔎 Interact with slicers & filters to explore different KPIs.
⚙️ If filters are applied, use the VBA macro button to clear all filters.
